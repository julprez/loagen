# Diagnóstico

Reproduce el fallo con una entrada pequeña. Lee el error completo y localiza su causa antes de editar. Añade una regresión y confirma que falla antes del arreglo. Aplica el cambio mínimo y vuelve a comprobar el comportamiento. No omitas tests, no rebajes assertions y no uses supresiones para ocultar errores. No confundas comandos propuestos con comandos ejecutados; informa bloqueos y trabajo pendiente.
